# Veila Skin

Your daily moment of care.

Website project for Veila Skin, a new skincare brand concept.

## Creative direction

- Brand wordmark: VEILA
- Palette: warm ivory, muted sage, soft blush
- Style: elegant typography, clean product photography, calm layouts
- Planned experience: product browsing, brand story, and a daily ritual section

## Project status

Repository setup is in progress. Website implementation and deployment have not started.
Product details are concept content until finalized. Brand and domain availability have not been verified.

## Working on this project

Open this repository folder in Antigravity to work on the website. Use GitHub to synchronize changes between tools.

Setup and run instructions will be added when the website framework is selected.
